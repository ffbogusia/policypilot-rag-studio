# Password Security Policy

## Purpose

This policy defines password requirements and safe password handling rules for company systems.

## Password requirements

Passwords must be unique, difficult to guess, and must not be reused across personal and company accounts.

## Password sharing

Employees must not share passwords through email, chat, tickets, documents or verbal communication.

## Password managers

Approved password managers may be used to store company credentials securely.

## Password reset

Password reset requests must follow the official identity verification process. IT Support must not reset passwords based only on informal chat requests.

## Compromised passwords

If a password may have been exposed, the user must change it immediately and report the incident to IT Support or Security Operations.
