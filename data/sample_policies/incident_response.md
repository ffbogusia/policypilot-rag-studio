# Incident Response Policy

## Purpose

This policy describes how employees should report and respond to suspected security incidents.

## Phishing emails

If an employee receives a suspicious email, they should not click links or open attachments. The email should be reported to Security Operations as soon as possible.

## Malware suspicion

If malware is suspected, the employee should disconnect from the network if instructed by Security Operations and preserve evidence.

## Lost or stolen device

A lost or stolen company device must be reported immediately to IT Support and Security Operations.

## Evidence handling

Employees should not delete suspicious messages, logs or files unless instructed by Security Operations.
